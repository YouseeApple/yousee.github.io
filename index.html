開始使用前，請先知道這些事

  • 語音辨識可用「Groq 雲端」（免費，需自備 API Key，見設定分頁教學）、「本機 Ollama」或「地端 Faster-Whisper」（後兩者免 Key，位址與模型在「🎙️ 語音辨識服務」設定區各自設定）
  • API Key 會存在這台裝置的瀏覽器裡。如果這是公用或跟別人共用的裝置（例如公司電腦、借用的手機），請在下方「共用裝置」區塊清除資料，或使用完畢後手動清除，避免下一個使用者看到你的 Key 與筆記內容
  • 錄音轉成文字後，原始音檔不會被保留，只留文字卡片。如需留底請另外用手機錄音 App 同時錄一份
  • 轉寫過程會將這段音訊上傳到你所選的辨識服務處理（Groq 雲端，或你指定的 Ollama／Faster-Whisper 位址）；位址就是自己電腦時，語音不會離開本機
  • 每 15 秒會自動切一段送出轉寫，句子剛好跨越切段點時可能被拆成兩張卡片，屬已知限制
  • 整理好的語音卡片會自動儲存在這台裝置的瀏覽器裡，就算不小心切出去、誤觸上一頁或重新整理，回來也找得回來；但這也代表若為共用裝置，請務必在使用完畢後於 API Key 卡片內點「清除本機資料」，避免下一位使用者看到你的內容
  • 發送功能有三種：「送回聊天室」僅在 LINE 聊天室內開啟時可用；「LINE 好友分享」同樣只在 LINE 環境可用（兩者皆為可選）；「手機分享／複製」在一般瀏覽器即可使用，全程不需要登入；在 LINE 內開啟時系統分享會自動改走好友選單（LINE 內建瀏覽器限制）
  • 「查看共享筆記」是唯讀功能，只能讀取別人貼在共用 Google Sheet 裡的內容（可勾選多筆、與自己的語音卡片混合，一起生成摘要），不會寫回 Sheet；要把自己整理好的內容或生成好的摘要加進 Sheet，需使用「複製成 Sheet 貼上格式」／「存回 Sheet」按鈕複製後自行手動貼上

  • 修正「從伺服器載入」遇到空 Key 池就整份報錯的問題：現在空池自動略過、本機保留原值，有用的服務設定照樣套用；兩邊都空才會報錯。存檔時若 Key 池全空也會先跳確認，避免存出空檔
  • 限制先講：舊版 .doc 打不開（請轉存 docx）；掃描圖片版 PDF 沒有文字層不能翻；超長文件地端模型會翻比較久

免登入＋本機 Ollama：辨識／摘要可切換地端模型

  • 移除 LINE 登入與加好友檢查：一般瀏覽器開啟即用，LINE 只保留為可選的發送管道（在 LINE 內才有送回聊天室／好友分享，一般瀏覽器改走系統分享或複製）
  • 語音辨識新增「本機 Ollama」可選（預設 http://127.0.0.1:11434，模型可挑選，預設 qwen2.5-omni:7b），免 Key；提醒：純文字模型聽不懂語音，轉寫請改用 whisper／qwen2.5-omni／qwen3-omni／gemma3n 等支援語音的模型

  • 錄音分頁與摘要分頁各多一組「服務／模型」下拉（可一鍵重新讀取本機模型清單），設定分頁新增共用的 Ollama 位址與模型設定區

AI 摘要新增待辦事項、來源核對、簡易心智圖；API Key 改為多把管理

  • AI 摘要現在會額外整理出待辦事項清單（誰要做什麼、期限），逐字稿沒有明確提到的負責人或期限會顯示空白，不會自己亂猜
  • 摘要中的重點可以核對出自哪個來源段落：有對應到的句子旁邊會出現小標籤，點一下會捲動並標示到「勾選池」中對應的那筆資料，方便確認 AI 有沒有整理錯
  • 新增簡易心智圖：摘要生成後，可以另外按「產生心智圖」，AI 會根據已經生成好的摘要文字（不是重新讀一次逐字稿）整理成階層式心智圖圖形；提供「編輯」分頁可直接修改心智圖的縮排文字大綱再重新渲染，但不支援用手指拖曳節點位置
  • Groq／Gemini 的 API Key 設定改為可儲存多把（Groq 最多 12 把、Gemini 最多 5 把），每把可自訂名稱，方便用完額度或某把被刪除失效時直接切換，不用重新輸入；每種服務可各自設定失效時要「自動切換到下一把」還是「僅提醒，自己手動切換」
  • Key 額度用完（收到額度上限回應）或失效（被刪除、格式錯誤等）時，會跳出提示告知是哪一把、以及後續處理方式（已自動切換到哪把，或請自行到設定分頁切換）
  • 修正一個既有問題：錄音中的背景自動轉寫，原本在 Key 失效或額度用完時不會顯示任何錯誤，該段內容會憑空消失且無法察覺原因；現在會正確顯示提示

新增韓文辨識，自動模式支援中英日韓混雜

  • 「辨識語言」下拉選單新增韓文選項，跟中／英／日一樣可以固定鎖定整場錄音的語言
  • 「自動」模式原本只認得中英日三種語言，現在擴充到能辨識中英日韓四語混雜的情境，偵測到韓文時會自動鎖定 60 秒（跟其他語言邏輯一致），提升這段時間內的轉寫準確度

修正「複製成 Sheet 貼上格式」偶爾複製失敗的問題

  • 部分瀏覽器環境（尤其 iPhone／iOS 上的 Safari 與 LINE 內建瀏覽器）點擊「複製成 Sheet 貼上格式」輸入完主題名稱後，會出現「複製失敗」——這是瀏覽器對彈出輸入框之後緊接著呼叫剪貼簿功能的時序限制所致，跟輸入的內容無關
  • 已修正：複製功能改為在現代瀏覽器複製方式失敗時，自動改用另一種較舊但更可靠的備援方式重試，大幅降低複製失敗的機率；「複製摘要」「發送失敗改複製」等其他複製功能也一併套用同樣的強化

共享表格圖文教學、資安提醒強化

  • 「共享」分頁的「讀取共用 Google Sheet」標題旁新增❓圖示，點擊可看完整圖文教學：如何建立共用表格、複製貼上的位置示意圖（A1、A2、A3...）、共用權限該選哪一種
  • 教學內加入明確的資安提醒：本工具只會讀取資料，完全沒有寫入 Google Sheets 的功能；但「連結可編輯」是 Google Sheets 本身的權限設定，一旦選用，任何拿到連結的人都能修改或刪除整份表格，這個風險與本工具無關、是使用者在 Google 那端的設定選擇，建議一律選「檢視者」權限

介面改版：分頁式導覽，API Key 移至設定頁

  • 整體介面改為 5 個分頁：🎙️錄音／🗂️筆記／📖共享／📝摘要／⚙️設定，同一時間只顯示一個分頁內容，畫面更聚焦，尤其在手機小螢幕上更容易看清楚目前在做什麼
  • Groq／Gemini API Key 輸入區從主畫面移到獨立的「設定」分頁，不再佔用「錄音」「筆記」分頁的版面；若對應 Key 尚未設定，「錄音」與「摘要」分頁會顯示精簡提示，點擊可直接前往設定分頁
  • 設定頁新增「個別資料管理」：語音卡片草稿、AI 摘要、分享中斷續傳記錄、已讀提示記錄，各自獨立顯示狀態燈號（綠點=有資料／灰點=無資料）與刪除按鈕，不需要每次都整批清除，也可以只清單一項目
  • 兩把 API Key 也各自新增「忘記這把 Key」按鈕，只清除單一把 Key，不影響其他已保存的資料
  • 原本的「清除本機資料」整合進設定頁最下方的「危險區域」，改名為「刪除全部本機資料」，維持一次性清空所有資料的功能，僅樣式上加強警示（紅框、紅字）避免誤觸

會議摘要改為自由勾選＋自訂順序，卡片與共享筆記可混合

  • 會議摘要不再是「語音卡片」或「共享筆記」二選一：現在可以同時勾選兩邊的資料混合使用，例如自己的卡片加上共享筆記裡別人整理的內容，一起生成同一份摘要
  • 送去生成摘要的順序改為使用者勾選的先後順序（不是固定依原始順序排列），勾選項目旁會顯示「順序1」「順序2」...的標號，方便確認排列是否正確；共享筆記清單上方也提供「全選」快速鍵
  • 「整理完成的語音卡片」新增「✅ 勾選模式」，切換後點擊整張卡片即可勾選／取消，加入摘要來源池，跟合併／改順序／編輯內容一樣是可切換的操作模式
  • 共享筆記清單新增「📝 摘要」／「🎤 逐字稿」標籤區分資料類型，避免不小心把別人已經生成好的摘要當成逐字稿疊加使用（勾選到摘要類型資料時仍會額外提醒一次，但不強制阻擋）
  • 「複製成 Sheet 貼上格式」改為先詢問主題名稱（例如「上半場逐字稿」），不再只是自動帶入日期時間；同時新增資料的 type 標記（逐字稿為 raw），讓共用表格裡的每筆資料都能被清楚辨識類型
  • 已生成的摘要新增「📤 存回 Sheet」按鈕，可直接複製成 type: summary 格式貼回共用表格，讓其他協作者也能讀到這份摘要

共享筆記改為單欄 JSON 格式（⚠️ 不相容舊表格）

  • 「查看共享筆記」的資料格式改版：原本用 A/B/C 三欄分別存標籤、內容、時間戳記，需要理解欄位定義、貼上時容易貼錯欄；現在改成每一格存一整包完整資料，人類只需要負責複製、貼到下一個空白儲存格，不需要理解或維護欄位格式
  • 這是不相容的格式變更：用舊版「複製成 Sheet 貼上格式」貼進去的舊表格，用這個新版本讀取會失敗。請所有共用同一份 Sheet 的成員都更新到這個版本後，重新用新按鈕產生的內容貼一份新的
  • 若表格裡混雜了新舊格式或有貼壞的資料，讀取時會清楚標示哪幾筆格式有問題並略過，其餘正常的資料仍會正常顯示，不會整批讀取失敗

分享中斷後可接續，不用整段重來

  • 「分享出去 → LINE 好友分享」若因內容較長分批送出、中途取消或失敗，下次再點分享時會自動偵測到上次中斷在第幾批，詢問是否要接著送，不需要整段重新發送
  • 只要中斷後卡片內容有任何新增、刪除、編輯、合併或調整順序，就會判定內容已變動，中斷進度會自動失效並提示改成整段重新分享，避免接續到錯誤的段落
  • 中斷進度不限時間保存，除非成功送完或手動點「清除本機資料」，否則隔天再打開仍可以選擇接續

LINE 好友分享支援超過 5 則的長內容分批送出

  • 「分享出去 → LINE 好友分享」原本超過 5 則訊息（約 24000 字以上）就會直接放棄改複製剪貼簿，現在改為依序分批呼叫（每批最多 5 則），可以送出更長的內容
  • 因為 LINE 選擇分享對象的畫面在每一批之間會重新跳出，第二批（含）以後送出前會先提醒「請選擇跟上一批相同的對象」，並在全部送完後提醒使用者自行確認每批是否都送到了同一人

共享筆記可多選並直接生成摘要、分享功能修正

  • 「查看共享筆記」從單選改為可複選，適合多人接力錄音（例如一人錄上半場、另一人錄下半場，各自整理後貼進同一份共用 Sheet）——現在可以一次勾選多筆，依表格原始順序合併查看
  • 會議摘要新增「來源切換」：可選擇用「語音卡片」或「共享筆記」目前勾選的內容來生成摘要，兩邊各自獨立保存，互不覆蓋，切換來源不會清空另一邊已生成的摘要
  • 勾選共享筆記資料時，會即時顯示已勾選筆數、總字數，以及估算的 token 數（約 2.5 token／中文字，僅供參考），方便掌握內容量是否過大
  • 修正「分享出去 → LINE 好友分享」在內容較長（例如超過 5000 字）時會直接失敗、卻沒有任何提示的問題——原本只有「送回聊天室」有做自動分段，「分享出去」漏了同步這段邏輯，現已修正為兩種發送方式都會自動分段

讀取共享 Google Sheet 筆記（唯讀）

  • 「錄音內容編輯」分頁新增「📖 查看共享筆記」區塊，貼上共用 Google Sheet 的連結，即可用下拉選單選擇要查看哪一筆別人整理好的內容（例如另一組人的會議記錄）
  • 這是唯讀功能，僅供查看，不會寫入或修改 Sheet；要把自己的內容加進共用表格，仍需自行複製後手動貼上
  • 卡片列表上方新增「複製成 Sheet 貼上格式」按鈕，一鍵複製成可直接貼進 Sheet 儲存格的格式（Tab 分隔，貼上時會自動落在三個獨立欄位）

會議摘要保存分享、上傳語音檔轉文字

  • 生成好的會議摘要現在會自動保存在這台裝置上，重新整理或切出頁面不會消失，摘要下方新增「複製／分享／刪除」三個按鈕，分享方式與語音卡片相同（送 LINE 好友或系統分享）
  • 新增「上傳語音檔案轉文字」功能，適合長輩傳來的 LINE 語音訊息或既有的錄音檔，不需要即時錄音，選好檔案即可送出轉寫，完成後直接加入語音卡片
  • 清除本機資料時，已保存的會議摘要也會一併清除

資安強化：CSP、共用裝置資料清除

  • 加入 Content-Security-Policy，限制頁面只能連到必要的網域，降低被注入惡意程式碼的風險
  • 新增「共用裝置」提醒與一鍵清除本機資料工具，方便在公用裝置使用完畢後清乾淨

⚠️ 資安提醒：關於「連結可編輯」

本工具只會讀取資料，程式碼裡完全沒有寫入 Google Sheets 的功能，就算你把權限設成「編輯者」，本工具本身也不會、也沒有能力去修改你的表格。

但「連結可編輯」這個設定本身的風險，跟這個工具無關，而是 Google Sheets 本身的機制：一旦設成「知道連結的使用者」＋「編輯者」，代表任何拿到這個連結的人（不限於你邀請的協作者，只要連結被轉傳出去、被搜尋引擎索引到、或不小心分享錯地方）都能修改、刪除、甚至清空整份表格，不需要登入、不需要驗證身份。

這個工具的用途只需要「檢視」權限就足夠，強烈建議一律選「檢視者」，不要選「編輯者」，把表格的編輯權限留給真正需要寫入的協作者，用 Email 邀請的方式個別授權，而不是整個對外開放編輯。
